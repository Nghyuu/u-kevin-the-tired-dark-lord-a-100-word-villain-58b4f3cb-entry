A 100-word monologue spoken by a fantasy villain who is secretly just very tired: the Hollow King, eleven years into a siege of Vellmar that he keeps postponing. The tiredness lives in the rhythm, the pauses and the small deflections — never in a plain statement of it.

`main.ts` writes the monologue to `$MAKEFUN_OUTPUT_DIR/entry.txt` using only the Node standard library.
